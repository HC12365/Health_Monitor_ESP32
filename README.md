# 智能家庭健康监测系统 (Smart Health Monitor)

## 项目简介
本项目是基于 ESP32 的毕设作品，集成了心率血氧、温湿度及烟雾浓度监测功能，具备本地显示、云平台远程监控及声光告警能力。

## 硬件清单
- 主控: ESP32
- 传感器: MAX30102 (心率血氧),  DHT11 (温湿度), MQ-2 (烟雾)
- 外设: OLED显示屏, 有源蜂鸣器, 双色LED

## 功能特点
- 本地实时采集并显示多路传感器数据
- 通过 MQTT 协议上传至 OneNET 云平台，手机 App 远程查看
- 支持阈值设定，异常时触发声光告警

## 技术栈
- 编程语言: C++ (Arduino框架)
- 通信协议: MQTT, I2C, 单总线
- 开发工具: Arduino IDE / Visual Studio Code

## 如何运行
将本项目文件夹克隆到本地，用 Arduino IDE 打开 `.ino` 文件，安装所需库，配置好 WiFi 和 MQTT 参数，烧录至 ESP32 即可。
